# Rectangle Control Button Styles Update

## Описание изменений

Обновлены стили кнопок риска в окне Rectangle Control для соответствия стилю Trading Toolbar.

## Изменения в файлах

### Controls/TradeRectangleControl.xaml
- Изменен `Background` кнопок риска с `White` на `LightGray`
- Теперь все кнопки риска имеют серый фон по умолчанию

### Controls/TradeRectangleControl.xaml.cs
- Добавлен метод `HighlightSelectedRiskButton(double risk)` для подсветки активной кнопки
- Изменена логика в `RiskButton_Click()` - теперь используется оранжевый цвет для активной кнопки
- Добавлена инициализация в конструкторе - кнопка с риском 1 активна по умолчанию
- Удален устаревший метод `ResetRiskButtonColors()`

## Новый стиль кнопок

- **Неактивные кнопки**: серый фон (`LightGray`)
- **Активная кнопка**: оранжевый фон (`Orange`)
- **По умолчанию**: активна кнопка с риском 1

## Соответствие Trading Toolbar

Стиль теперь полностью соответствует кнопкам в Trading Toolbar:
- Кнопки RISK: белый фон для неактивных, оранжевый для активных
- Кнопки TIME: серый фон для неактивных, оранжевый для активных
- Rectangle Control: серый фон для неактивных, оранжевый для активных

## Тестирование

Для проверки изменений:
1. Запустите приложение
2. Откройте Rectangle Control
3. Убедитесь, что кнопки имеют серый фон
4. Убедитесь, что кнопка с риском 1 подсвечена оранжевым
5. Нажмите на другие кнопки риска - они должны подсвечиваться оранжевым
