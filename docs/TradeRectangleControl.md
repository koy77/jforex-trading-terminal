# TradeRectangleControl

## Описание
`TradeRectangleControl` - это пользовательский WPF контрол для отображения торговых операций по прямоугольнику. Контрол показывает информацию о символе, верхней и нижней цене, а также предоставляет кнопки для покупки/продажи с настраиваемым риском.

## Основные компоненты

### События
- `BuyClicked` - вызывается при нажатии кнопки покупки
- `SellClicked` - вызывается при нажатии кнопки продажи  
- `RiskChanged` - вызывается при изменении выбранного риска

### Свойства
- `SelectedRisk` - текущий выбранный риск (по умолчанию 1)

## Методы

### SetRectangleData(string symbol, double upperPrice, double lowerPrice)
Устанавливает данные для отображения в контроле:
- `symbol` - торговый символ
- `upperPrice` - верхняя цена прямоугольника
- `lowerPrice` - нижняя цена прямоугольника

### SetRisk(double risk)
Устанавливает значение риска извне (например, из Trading Toolbar):
- `risk` - значение риска

### Show()
Показывает контрол (устанавливает Visibility в Visible)

### Hide()
Скрывает контрол (устанавливает Visibility в Collapsed)

### HighlightSelectedRiskButton(double risk)
Подсвечивает выбранную кнопку риска оранжевым цветом, остальные - серым

## Логика торговли

### Покупка (Buy)
- Цена входа: `upperPrice`
- Стоп-лосс: `lowerPrice`
- Тип операции: "buy"

### Продажа (Sell)
- Цена входа: `lowerPrice` 
- Стоп-лосс: `upperPrice`
- Тип операции: "sell"

## Кнопки риска
Контрол содержит кнопки для выбора риска (1, 2, 3, 5). Выбранная кнопка подсвечивается оранжевым цветом, остальные - серым.

## Безопасность потоков
Все операции с UI выполняются через `Dispatcher.Invoke()` для обеспечения безопасности при работе из других потоков.

## Использование
```csharp
var control = new TradeRectangleControl();
control.SetRectangleData("EURUSD", 1.0850, 1.0840);
control.SetRisk(2);
control.Show();

control.BuyClicked += (sender, args) => {
    // Обработка покупки
};
```
