# TradePriceLevelControl

## Описание
`TradePriceLevelControl` - это пользовательский WPF контрол для отображения торговых операций по Price Level. Контрол показывает информацию о символе, цене входа (Entry Level), а также предоставляет текстовые указания для покупки/продажи с настраиваемым риском.

## Основные компоненты

### События
- `RiskChanged` - вызывается при изменении выбранного риска

### Свойства
- `SelectedRisk` - текущий выбранный риск (по умолчанию 1)

## Методы

### SetPriceLevelData(string symbol, double entryPrice)
Устанавливает данные для отображения в контроле:
- `symbol` - торговый символ
- `entryPrice` - цена входа (Entry Level)

### SetRisk(double risk)
Устанавливает значение риска извне (например, из Trading Toolbar):
- `risk` - значение риска

### Show()
Показывает контрол (устанавливает Visibility в Visible)

### Hide()
Скрывает контрол (устанавливает Visibility в Collapsed)

### HighlightSelectedRiskButton(double risk)
Подсвечивает выбранную кнопку риска оранжевым цветом, остальные - серым

## Визуальные элементы

### Темная тема
- Темно-серый фон (`#2D2D30`) с серой рамкой (`#3F3F46`)
- Белый текст для символа
- Современные цвета для всех элементов

### Entry Level
- Отображается бирюзовым цветом (`#4ECDC4`) в центре контрола
- Показывает цену входа в формате "Entry Level: 0.00000"

### Place Sell
- Текст "Sell stop loss above" отображается красным цветом (`#FF6B6B`)
- Расположен над Entry Level
- Простая текстовая метка

### Place Buy
- Текст "Place Buy stop loss below" отображается синим цветом (`#74B9FF`)
- Расположен под кнопками риска
- Простая текстовая метка

## Кнопки риска
Контрол содержит кнопки для выбора риска (1, 5, 10, 20, 30) - идентичные TradingToolbar. 
- Выбранная кнопка: оранжевый фон (`#FFA500`) с белым текстом
- Неактивные кнопки: темно-серый фон (`#4A4A4A`) с белым текстом

## Логика отображения

### Автоматическое скрытие
- Контрол автоматически скрывается при установке Stop Loss Price
- Используется только для отображения информации о Entry Level

## Управление
- **Escape** - скрывает контрол (отмена)

## Безопасность потоков
Все операции с UI выполняются через `Dispatcher.Invoke()` для обеспечения безопасности при работе из других потоков.

## Использование
```csharp
var control = new TradePriceLevelControl();
control.SetPriceLevelData("EURUSD", 1.0850);
control.SetRisk(5);
control.Show();

control.RiskChanged += (sender, risk) => {
    // Обработка изменения риска
};
```

## Интеграция с SimpleTradingOverlay
Контрол интегрируется с `SimpleTradingOverlay` и отображается при получении события Price Level из JForex. Позиционируется в том же месте, что и `TradeRectangleControl`.
